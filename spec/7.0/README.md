# GEDCOM 7.0 terms

`terms/` is an unmodified copy of `extracted-files/tags/` from the FamilySearch GEDCOM
specification repository: <https://github.com/FamilySearch/GEDCOM>, tag `v7.0.18`, commit
`2f0b863b5a42275bd2b3ca315900cf779e42f28b`. The files use the term format described at
<https://gedcom.io/terms/format>. License: Apache-2.0 (`LICENSE`, `NOTICE`).

To update, copy `extracted-files/tags/` of a newer 7.0.x tag over `terms/`, update the tag and
commit above and in `bin/generate-profiles.php`, then run `php bin/generate-profiles.php`.
